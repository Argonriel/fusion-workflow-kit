# Edit round record

Copy this template into a local, private `round_records/` folder or the project's
design-review output folder. Keep completed records out of the public workflow
repository. Do not replace or edit genuine guard reports.

## Cloud checkpoint

- Version before the save:
- Confirmed version after the save and exact version ID:
- Save acceptance report reference and confirmation time:
- Same intended working identity and destination verified:
- Cloud processing complete for the expected new version:
- No remaining unsaved changes; model unchanged by saving:
- Source and unrelated document preservation evidence:

For a read-only round, record the verified existing version and mark the save as
not applicable. For a save already accepted after the last change, reference its
evidence rather than creating a duplicate version. For a blocked save, retain the
error/evidence, keep the round incomplete and record the permitted next action.

- Working file location and confirmed version for the next person:

- Completion: every changed working file has accepted model evidence and a
  confirmed Fusion cloud version; all exceptions remain explicitly incomplete.
